# Backend для LLM анализа документов

## Быстрый старт

1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

2. Запуск сервера:
```bash
python app.py
```

Сервер запустится на `http://localhost:5000`

## Структура проекта
```
backend/
├── app.py              # Основной файл с Flask API
├── requirements.txt    # Зависимости
├── uploads/           # Папка для загруженных файлов (создаётся автоматически)
└── README.md          # Этот файл
```

## API Endpoints

### GET /api/health
Проверка работоспособности сервера.

**Response:**
```json
{
  "status": "ok",
  "message": "Backend is running"
}
```

### POST /api/upload
Загрузка и анализ документа.

**Request:** multipart/form-data с полем `file`

**Response:**
```json
{
  "success": true,
  "filename": "document.pdf",
  "file_id": "1234567890_document.pdf",
  "analysis": {
    "summary": "...",
    "key_points": [...],
    "entities": {...},
    "document_type": "..."
  }
}
```

### POST /api/chat
Общение с ботом о документе.

**Request:**
```json
{
  "message": "Что написано в этом документе?",
  "file_id": "1234567890_document.pdf",
  "document_context": {...},
  "chat_history": [...]
}
```

**Response:**
```json
{
  "success": true,
  "thinking_steps": ["шаг 1", "шаг 2", ...],
  "response": "Ответ бота"
}
```

## Примеры использования

### Python (requests)
```python
import requests

# Загрузка файла
files = {'file': open('document.pdf', 'rb')}
response = requests.post('http://localhost:5000/api/upload', files=files)
result = response.json()

# Отправка сообщения
data = {
    "message": "Расскажи о главном в документе",
    "file_id": result['file_id'],
    "document_context": result['analysis']
}
response = requests.post('http://localhost:5000/api/chat', json=data)
```

### JavaScript (fetch)
```javascript
// Загрузка файла
const formData = new FormData();
formData.append('file', fileInput.files[0]);

const uploadResponse = await fetch('http://localhost:5000/api/upload', {
  method: 'POST',
  body: formData
});

// Отправка сообщения
const chatResponse = await fetch('http://localhost:5000/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    message: "Что это за документ?",
    file_id: uploadResponse.file_id,
    document_context: uploadResponse.analysis
  })
});
```
