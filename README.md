# RAG-система для корпоративной базы знаний

Проект реализован для компании **МК Сплав** 

## Что это

ChatGPT по внутренним документам. Спрашиваешь - получаешь ответ со ссылками.

## Как работает

**Бэк:**
- Парсим все документы (doc, pdf, rtf), вытаскиваем текст
- Делаем embeddings через SBERT модель
- На вопрос ищем похожие куски, прогоняем через reranker, отдаем в LLM

**Фронт:**
- Обычный чат как в ChatGPT
- История диалогов

## MVP

Работает поиск и ответы, есть интерфейс.

## Стек

- Python, SBERT модель, LLM
- HTML, CSS, React
